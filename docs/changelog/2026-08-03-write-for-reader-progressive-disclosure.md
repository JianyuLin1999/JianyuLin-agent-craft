# write-for-reader 改为按需加载场景要求

## Skill 文件怎样调整

- `SKILL.md` 从 140 行缩短为场景判断、文件路由和所有写作任务共同保留的要求。
- 外行讲解、技术调查、学术写作、PPT、工作文档和创意写作分别进入 `profiles/` 下的独立文件。
- 普通任务只加载一个 profile。混合成品最多增加一个次要 profile，主要文件决定结构。
- 长文、高风险内容和严格重写才加载 `AUDIT.md`。普通短答不携带完整检查清单。
- 版本从 0.1.0 更新为 0.2.0。

## HTML 怎样调整

- 正文主要篇幅改为分析 AI 文字令人不满的七个层面：读者起点、信息顺序、对象与因果、证据与判断、作者姿态、句式节奏和页面形式。
- 每一层分别说明常见症状、读者承担的额外工作、AI 容易出现这种写法的原因和修正步骤。
- 场景自动判断压缩成一张流程图。
- 新增二维象限图。横轴表示读者已有知识，纵轴表示决定或行动压力；点击场景可以查看特定要求和加载文件。
- 页面末尾可以切换、复制和打开完整的多文件 Skill 包。
