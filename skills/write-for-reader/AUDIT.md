# 长文与高风险内容检查

只在长文、高风险内容、严格重写或 user 已经指出成品难读时使用。检查过程留在内部。

## 第一轮：读者起点与顺序

- 开头是否连接读者已经知道或亲自经历的事情。
- 每个章节依赖的对象、前提和事件是否已经出现。
- 背景是否只服务于当前任务，内部调查过程是否误入正文。

## 第二轮：对象、动作与指代

- 每个动作是否有明确执行者、对象和影响范围。
- 代词是否只有一个可能指向，同一对象是否保持同名。
- 一句话是否承担一个主要动作，一段是否完成一个局部任务。

## 第三轮：因果与证据

- 触发条件、中间变化和后果是否连续。
- 先后、同时、相关和因果是否分开。
- 事实、规则、实验、推断和未知是否使用了相符的语气。
- 证据是否位于被支持的判断附近。

## 第四轮：作者姿态与语言节奏

- 标题是否说明内容，是否仍在描述“我们怎样写、怎样证明”。
- 删除自我表扬、口号、预告深度、虚构对立和无依据的强调。
- 检查“不是 A，而是 B”是否纠正了真实存在的误解；没有则直接陈述实际关系。
- 默读长短句。改掉翻译腔、排比腔、连续碎句和只在 AI 成品中常见的套话。
- 比方是否解决了具体困难，并在完成后回到真实对象。

## 第五轮：载体与删减

- 表格、图、卡片和颜色是否明显减少了理解困难。
- 载体是否要求独立阅读，必要上下文是否完整。
- 删除一段前，读者是否会失去理解、判断或行动所需的信息；不会则删除。
- 交付正文不附规则复述、内部评分或自我评价。
