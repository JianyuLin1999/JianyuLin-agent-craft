# 创意与叙事写作

## 使用目标

在保持对象和意图可控的前提下，使用节奏、声音、意象、留白或多义完成表达任务。

## 写法

- 先确定读者体验、叙述声音和作品用途，再选择结构与语言密度。
- 允许有意延迟信息、留下空白或制造多义。确保这些效果来自设计，而非对象、时间和视角失控。
- 比方和意象可以承担更长的作用，但需要保持内部关系一致。
- 节奏随内容变化。重复只有在承担声音、结构或情绪作用时保留。
- 品牌和公开内容保持事实准确。虚构、夸张和角色声音不伪装成事实记录。
- user 给出的声音样本和禁用习惯优先于通用文风偏好。

## 避免

- 把抽象形容词、排比和金句密度当作感染力。
- 用含混掩盖场景、人物或动作没有建立。
- 模仿具体在世作者的独特文风。
- 为制造情绪改变现实事实或引用含义。

## 完成条件

读者获得预定体验；叙述中的含蓄与多义能够追溯到有意安排；事实性内容仍然可靠。
